# Fonts

Subsets of **Noto Sans Devanagari**, **Noto Sans Tamil** and **Noto Sans Kannada**
(Regular 400 and Bold 700), © 2022 The Noto Project Authors, licensed under the
SIL Open Font License 1.1 (see `OFL.txt`). Source: https://github.com/google/fonts

Each file keeps the complete Unicode block of its script (so anything a user
types still renders) and drops other scripts. They are bundled so Hindi, Tamil
and Kannada display correctly on phones that lack these fonts, and they are
cached by the service worker for offline use.
